# Portfolio Template

This is a complete portfolio website template that demonstrates all the HTML, CSS, and JavaScript concepts covered in the main tutorial.

## Getting Started

1. **Copy this folder** to create your own portfolio
2. **Customize the content** with your own information
3. **Replace placeholder images** with your actual project screenshots
4. **Update links** to point to your real projects and social media
5. **Deploy** using Vercel or your university's public_html folder

## Files Included

- `index.html` - The main HTML structure
- `style.css` - All the CSS styling and animations
- `script.js` - JavaScript for interactivity and animations

## Customization Guide

### Personal Information
- Replace "Your Name" throughout the HTML
- Update the email and social media links in the contact section
- Add your own profile photo (replace the placeholder image URL)

### Projects Section
- Replace the placeholder project images with screenshots of your work
- Update project titles, descriptions, and technologies used
- Add links to your live projects and GitHub repositories

### About Section
- Write your own biography and interests
- Replace the placeholder profile image

### Skills Section
- Update the skills lists with technologies you actually know
- Add or remove skill categories as needed

### Colors and Styling
- Change the color scheme by updating the CSS custom properties
- Modify fonts by changing the `font-family` declarations
- Adjust spacing and sizing to match your preferences

## Advanced Features Included

- **Responsive design** that works on all devices
- **Smooth scrolling** navigation
- **Fade-in animations** as you scroll
- **Parallax effects** on the hero section
- **Interactive hover effects** on project cards
- **Typing animation** on the hero subtitle
- **Mobile-friendly** navigation
- **SEO optimized** with proper meta tags

## Deployment Instructions

1. **For Vercel:**
   - Upload this folder to GitHub
   - Connect your GitHub repository to Vercel
   - Your site will be live automatically!

2. **For university public_html:**
   - Upload all files to your public_html directory
   - Make sure `index.html` is in the root
   - Access via your university URL

## Tips for Success

- **Keep it updated** - Add new projects as you complete them

- **Test thoroughly** - Check your site on different devices and browsers
