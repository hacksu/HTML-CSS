# Portfolio Customization Guide

This guide will help you personalize your portfolio template and make it truly yours!

## 🎯 Getting Started

### 1. Basic Information Updates
**Files to edit:** All HTML files (`index.html`, `about.html`, `projects.html`, `skills.html`, `contact.html`)

- Replace "Your Name" with your actual name
- Update email addresses from `your.email@example.com` to your real email
- Change social media usernames from `yourusername` to your actual usernames

### 2. Homepage Customization (`index.html`)
- **Hero Title**: Change "Hi, I'm Your Name" to your actual name
- **Subtitle**: Update "Web Developer & Designer" to reflect what you do or want to be known for
  - Examples: "Computer Science Student", "Aspiring Software Engineer", "Frontend Developer"
- **Description**: Write 1-2 sentences about yourself
- **Emojis**: Pick emojis that represent you in the preview cards
- **Preview Text**: Update the descriptions to match your actual content

## 📖 About Page (`about.html`)

### Your Story
Look for these placeholders and replace them:
- `[tell your story here]` - How did you get into web development?
- `[add your hobbies/interests here]` - What do you enjoy outside of coding?
- `[your current goals]` - What are you working toward?

### Photo & Caption
- Replace the placeholder image with your actual photo
- Update the image caption with something that represents you

### Statistics
Update the numbers to reflect your actual experience:
- Projects completed (count everything, even small ones!)
- Programming languages you've tried
- Add more stats if you want (years learning, courses completed, etc.)

## 💼 Projects Page (`projects.html`)

### Adding Your Projects
For each project, you'll need:
1. **Screenshot**: Take a picture of your project in action
2. **Title**: Give your project a clear, descriptive name
3. **Description**: 2-3 sentences about what it does and what makes it special
4. **Technologies**: List the actual tools you used
5. **Links**: Add links to the live demo and your code

### Project Ideas for Beginners
- Personal website or blog
- Simple calculator
- To-do list app
- Weather app using an API
- Recipe finder
- Color palette generator
- Basic game (tic-tac-toe, rock-paper-scissors)

### Blank Templates
Use the blank project templates at the bottom of the file:
1. Copy a blank project card
2. Fill in your information
3. Remove the placeholder brackets
4. Repeat for each project

## ⚡ Skills Page (`skills.html`)

### Skill Categories
Organize your skills into categories like:
- **Frontend**: HTML, CSS, JavaScript, React, etc.
- **Backend**: Python, Java, Node.js, databases, etc.
- **Tools**: VS Code, Git, GitHub, Figma, etc.
- **Learning**: What you're currently studying

### Rating Yourself Honestly
- **20-30%**: Beginner (just started learning)
- **40-60%**: Intermediate (can build basic projects)
- **70-85%**: Advanced (comfortable with most features)
- **90%+**: Expert (could teach others)

### Adding New Skills
1. Use the blank skill template
2. Pick an appropriate emoji
3. Write what you know about that technology
4. Set an honest skill level percentage

## 📬 Contact Page (`contact.html`)

### Contact Information
- Update all email addresses
- Replace social media usernames
- Add or remove contact methods as needed
- Consider adding platforms like Discord, Twitter, or Portfolio sites

### Form Customization
- Update the form placeholder text
- Modify the welcome message
- Customize the FAQ section with questions relevant to you

## 🎨 Design Customization (`style.css`)

### Colors
Look for the `:root` section at the top of `style.css` to change colors:
```css
:root {
    --primary-color: #3498db;    /* Main accent color */
    --secondary-color: #2c3e50;  /* Dark text color */
    --accent-color: #e74c3c;     /* Highlight color */
    --background-color: #f8f9fa; /* Page background */
}
```

### Popular Color Schemes
- **Blue Professional**: #3498db, #2c3e50, #e74c3c
- **Green Nature**: #27ae60, #2c3e50, #e67e22
- **Purple Creative**: #9b59b6, #34495e, #e74c3c
- **Orange Energetic**: #e67e22, #2c3e50, #3498db

### Fonts
To change fonts, update the `font-family` properties in the CSS file.

## 🚀 Advanced Customizations

### Adding New Sections
1. Study the existing HTML structure
2. Copy a similar section
3. Modify the content and classes
4. Add corresponding CSS if needed

### Adding Animations
The template includes basic animations. You can:
- Adjust animation speeds in the CSS
- Add new hover effects
- Modify scroll-triggered animations

### Adding More Pages
1. Copy an existing page as a template
2. Update the navigation menu in all pages
3. Add appropriate content
4. Link it properly in the navigation

## 🔧 Technical Tips

### Testing Your Changes
1. Save your files
2. Refresh your browser
3. Test on different screen sizes
4. Check that all links work

### Image Optimization
- Use `.jpg` for photos
- Use `.png` for graphics with transparency
- Keep file sizes under 1MB when possible
- Consider using online image compressors

### Code Organization
- Keep your HTML clean and properly indented
- Comment your changes in CSS
- Test one change at a time
- Make backups before major changes

## 📱 Mobile Responsiveness

The template is already mobile-friendly, but test your changes:
1. Resize your browser window
2. Use browser developer tools
3. Test on actual mobile devices if possible

## 🎯 Final Tips

### Content Writing
- Be authentic and genuine
- Keep descriptions concise but informative
- Proofread everything for typos
- Ask friends to review your content

### Photography
- Use good lighting for your profile photo
- Take clear screenshots of your projects
- Maintain consistency in image sizes
- Consider using free stock photos if needed

### Regular Updates
- Add new projects as you complete them
- Update your skills as you learn new technologies
- Refresh your bio as you grow and change
- Keep contact information current

## 🆘 Getting Help

If you get stuck:
1. Check the browser console for errors (F12)
2. Validate your HTML and CSS
3. Ask classmates or instructors
4. Search for solutions online
5. Start with small changes and build up

Remember: This is YOUR portfolio. Make it reflect who you are and what you're passionate about. Don't worry about making it perfect immediately - you can always improve it over time as you learn more and gain more experience!

Good luck building an amazing portfolio! 🌟
